# چک‌لیست انتشار «مسیر» در کافه بازار

## ۱. امضای ثابت (یک بار، الزامی)
بازار نسخه‌ی debug را نمی‌پذیرد و همه‌ی نسخه‌های بعدی باید با همان کلید امضا شوند.
در GitHub: Settings ← Secrets and variables ← Actions ← New repository secret
- `ANDROID_KEYSTORE_PASSWORD` — از فایل `paramis-signing-secrets.txt`
- `ANDROID_KEYSTORE_B64` — از همان فایل

سپس Actions ← Build APK ← Run workflow. فایل `Masir-1.0.N.apk` (بدون debug) در Releases ساخته می‌شود.

## ۲. ساخت برنامه در پیشخان بازار
1. پیشخان ← برنامه‌ی جدید ← بارگذاری APK امضاشده (شناسه‌ی بسته `tech.paramis.masir`).
2. متن صفحه، تصاویر، آیکون و حریم خصوصی را از `store/listing.md` و `store/privacy.md` وارد کنید. برای لینک حریم خصوصی می‌توانید نشانی همین فایل در GitHub را بدهید.

## ۳. پرداخت درون‌برنامه‌ای
1. در پیشخان، بخش «پرداخت درون‌برنامه‌ای» برنامه را باز کنید و کلید عمومی RSA را کپی کنید.
2. کلید RSA بازار داخل `android/app/build.gradle` گذاشته شده است (کلید عمومی است و محرمانه نیست). Secret `BAZAAR_RSA_KEY` فقط برای جایگزین کردن آن لازم است.
3. دو محصول از نوع «اشتراک» بسازید:
   - `masir_pro_monthly` — ماهانه — ۲۰٬۰۰۰ تومان
   - `masir_pro_yearly` — سالانه — ۱۲۰٬۰۰۰ تومان
   (اگر پیشخان دوره‌ی سالانه نداشت، به من بگویید تا اشتراک سالانه را به شکل دیگری پیاده کنم.)
4. دوباره Build APK را اجرا کنید و نسخه‌ی جدید را در پیشخان بارگذاری کنید. از این نسخه به بعد، صفحه‌ی «پلن پیشرفته» خرید را فعال می‌کند.

## ۴. آزمایش پیش از انتشار عمومی
- روی گوشی واقعی با اپ بازار نصب‌شده و واردشده به حساب، از صفحه‌ی «پلن پیشرفته» خرید ماهانه را امتحان کنید.
- بعد از خرید باید بتوانید «برنامه‌ی جدید» بسازید.
- «بازیابی اشتراک» را روی گوشی دوم یا بعد از نصب دوباره امتحان کنید.
- لغو اشتراک از اپ بازار؛ بعد از پایان دوره، برنامه‌ی دوم قفل و برنامه‌ی رایگان باز می‌ماند.

## ۵. ارسال برای بررسی
